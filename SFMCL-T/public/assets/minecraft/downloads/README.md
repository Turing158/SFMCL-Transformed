# 下载中心挖矿动画素材

素材取自[中文 Minecraft Wiki](https://zh.minecraft.wiki/)与[红河素材站](https://honghemc.cn/app/textures.html)，原始文件地址见 `sources.json`。游戏图像著作权属于 Mojang Studios；此处不将游戏图像标为 Wiki 文章的 CC 许可。

- `stone.png`：石头，Wiki 的 `Stone_JE5_BE3.png` 150px 立体缩略图。
- `pickaxe.png`：钻石镐，`Invicon_Diamond_Pickaxe.png`。
- `diamond-ore.png`：钻石矿石，`Invicon_Diamond_Ore.png`。
- `diamond.png`：钻石，`Invicon_Diamond.png`。
- `destroy_oit_stage_2.png`、`destroy_oit_stage_5.png`、`destroy_oit_stage_8.png`：26.3 半透明破坏纹理，分别对应第一次、第二次、第三次敲击。
- `destroy_oit_stage_*-cube.png`：上述原始纹理投影到立体方块三个可见面的透明覆盖层，使用最近邻采样并按石块轮廓裁剪。最后一级裂纹同时覆盖碎裂分片。

保留原始图像，界面采用像素化缩放。碎裂分片和庆祝光点由界面绘制。素材随应用本地打包，动画不请求素材站。
